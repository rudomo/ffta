FFTA Code Generator

Gameshark codes for character stats and generic names.

How values are calculated
  • Level-ups = Level − 1. Base = Base stat + (Growth + Bonus chance ÷ 10) × level-ups.
  • Min = (Base stat + Growth × level-ups) × Min Variation %, with no bonus gains.
  • Max = (Base stat + (Growth + 1) × level-ups) × Max Variation %, where a +1 bonus is counted only if the bonus chance is above 0.
  • Random picks a whole number between each stat's Min and Max result. It re-rolls when you change a control or press the refresh button, and stays fixed while you edit values.
  • Level uses the Lv code and follows the Level control. EXP uses the exp code; the job data has no EXP values, so it is a manual value that starts at 0 and is limited to a maximum of 99.
  • Results are rounded down to the nearest whole number and limited to 0–999. Codes are the slot's address followed by the value as 4 hex digits.
